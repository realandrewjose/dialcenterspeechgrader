# Public Speaking Grader - Desktop App

## Quick Start

**Double-click to launch the app:**
```
Public Speaking Grader.exe
```

Located in: `C:\Users\{YourUsername}\OneDrive\Desktop\Public Speaking Grader.exe`

Or use the batch file:
```
Run App.bat
```

---

## What You Get

✅ **Complete offline app** - Works without internet  
✅ **Three speech grading rubrics:**
- Symposium Research Presentation (150 pts)
- Informative Speech (200 pts)
- Persuasive Speech (250 pts)

✅ **Full-featured grader:**
- Score individual rubric items
- Add feedback notes
- Toggle "did/did not" for each criterion
- Auto-save scores locally
- Print summaries
- Copy feedback to clipboard
- Reset scores

---

## How to Use

### 1. **Opening the App**
- Double-click `Public Speaking Grader.exe`
- Dashboard appears with three options

### 2. **Choose Assignment Type**
Click one of the cards:
- **🎤 Symposium** - Academic research presentation (9 sections, 150 pts)
- **ℹ️ Informative** - Informative speech (10 sections, 200 pts)
- **🔥 Persuasive** - Persuasive speech with Monroe's Sequence (10 sections, 250 pts)

### 3. **Grade the Speech**
- **Score each section** by clicking the point box
- **Add feedback** using the "Glow" (positive) and "Grow" (improvement) tags
- **Notes section** at bottom for overall comments
- **Warnings** appear for common issues (e.g., missing citations)

### 4. **Export Results**
- **Print:** Click "Print Rubric" for a formatted PDF
- **Copy:** Click "Copy Summary" to copy all feedback to clipboard
- **Reset:** Click "Reset" to start over for a new student

### 5. **Go Back**
Click the **"← Back to Dashboard"** button to select a different assignment type

## Assignment Details

### Symposium Research Presentation (150 pts)
Evaluates academic presentations with focus on research depth and delivery.
- Overall presentation (15 pts)
- Introduction (20 pts)
- Body organization (20 pts)
- Content quality (20 pts)
- Conclusion (20 pts)
- Vocal delivery (15 pts)
- Physical delivery (15 pts)
- Q&A handling (15 pts)
- Group cohesion (10 pts) *if applicable*

### Informative Speech (200 pts)
Assesses information delivery without persuasive elements.
- Overall approach (20 pts)
- Introduction (25 pts)
- Body organization (25 pts)
- Content depth (30 pts)
- Conclusion (25 pts)
- Vocal delivery (20 pts)
- Physical delivery (20 pts)
- Outline quality (20 pts)
- Visual aids/slides (15 pts)

### Persuasive Speech (250 pts)
Evaluates speeches using Monroe's Motivated Sequence.
- **Attention** - Gets audience interest (30 pts)
- **Need** - Establishes problem/urgency (30 pts)
- **Satisfaction** - Provides solution (30 pts)
- **Visualization** - Shows consequences (30 pts)
- **Action** - Calls for specific action (30 pts)
- Overall effectiveness (20 pts)
- Outline quality (20 pts)
- Visual aids (10 pts)
- Vocal delivery (25 pts)
- Physical delivery (25 pts)

## Tips for Best Results

1. **Reference the rubrics** - Each section shows specific grading criteria
2. **Use tags** - "Glow" tags highlight strengths, "Grow" tags suggest improvements
3. **Be specific** - More detailed feedback helps students improve
4. **Check warnings** - Red warnings alert you to missing elements
5. **Print copies** - Create a record for your files

## Troubleshooting

### App won't launch
- Ensure Windows Defender doesn't block it
- Try running as Administrator
- Check that antivirus isn't quarantining the file

### Scores not saving
- Data saves automatically to your browser
- Try closing and reopening the app
- Check that you have write permissions to your Documents folder

### Print looks odd
- Use "Print to PDF" for a digital copy
- Print preview shows how it will look
